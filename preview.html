🚀 Cómo Probar la Aplicación

1

Instalar Flutter

Descarga desde flutter.dev

2

Configurar entorno

flutter doctor

Sigue las instrucciones para completar la instalación

3

Navegar al proyecto

cd app-abarrotes-mobile
4

Obtener dependencias

flutter pub get
5

Ejecutar la aplicación

flutter run

Conecta un dispositivo Android o usa un emulador

⚠️ Nota: Necesitas tener Android Studio instalado para el emulador o un dispositivo Android físico conectado.

lib/ ├── main.dart # Punto de entrada ├── models/ # Modelos de datos ├── providers/ # State management ├── screens/ # Pantallas ├── widgets/ # Componentes ├── theme/ # Tema └── utils/ # Utilidades
